# Inspiration sources

Named sources per surface. Every citation in the output must name one of
these (or a specific site the user linked) — never "sites like this" or
"modern design trends".

**Rule: extract the pattern, don't clone the artefact.** If a site inspires
a particular treatment, isolate the *idea* (dense editorial grid, oversized
serif set on a colour block, a scroll-driven type reveal) and apply it to
the target with the target's own content and brand. Never propose a
one-to-one copy.

## Sources per surface

### Whole sites, portfolios, high-concept marketing

- **Awwwards** — awwwards.com. Site of the day / month / year. Best for
  browsing complete design systems in the wild. Sort by category (Portfolio,
  Agency, E-commerce) to match the target type.
- **Godly** — godly.website. Curated Webflow + Framer sites, heavier on
  design agencies and studios than Awwwards. Good taste, well-tagged.
- **Land-book** — land-book.com. Landing-page focused. Filter by industry
  and by design element (hero, features, testimonials).
- **SiteInspire** — siteinspire.com. Older curation, less trend-driven,
  useful for design that will still look right in three years.
- **httpster** — httpster.net. Sharper editorial taste; more indie /
  personal / experimental than the others.
- **Minimal Gallery** — minimal.gallery. When the reference is "clean,
  restrained, editorial".

### Individual UI components

- **CollectUI** — collectui.com. One component a day, tagged by type
  (sign-in, dashboard, pricing table, empty state, etc.). Best for
  "what are the current conventions for [component]".
- **Mobbin** — mobbin.com. Real screenshots from real shipping apps, both
  web and mobile. Free tier is limited; paid tier ($15/mo) is the standard
  in-house tool for pattern research.
- **Pageflows** — pageflows.com. Onboarding + flow-level captures. Better
  than static screenshots when the pattern is a sequence, not a screen.
- **UI Sources** — uisources.com. Similar to Mobbin, complementary
  catalogue.

### Framer / Webflow templates and showcases

- **Framer Templates** — framer.com/templates. Filter by category. Even
  when not using Framer, the template gallery shows what a *complete*
  modern site looks like end-to-end.
- **Webflow Showcase** — webflow.com/made-in-webflow/websites. Massive
  volume, uneven quality — filter by "Editor's Picks" and "Most Popular".
- **Cofolios** — cofolios.com. Designer portfolios only — good for
  portfolio-shaped target work.

### Motion + interaction inspiration

- **Codrops** — tympanus.net/codrops. Tutorial-driven; every article ships
  a working demo. Best when the reference is a specific interaction
  (a hover, a page transition, a slider) rather than a whole site.
- **hover.dev** — hover.dev. Cards and buttons only, all with source code.
- **cssdesignawards.com** — CSSDA. Overlap with Awwwards; slightly
  different curation lens.

### Type in the wild

- **Typewolf** — typewolf.com. Best in class for typography-focused
  browsing. "Site of the day" is well-picked; the pairings list is a
  starting point for the typography stage.
- **Fonts In Use** — fontsinuse.com. Real-world type pairings across print,
  packaging, and web. Useful when justifying a pairing choice.

### Colour in the wild

- **Klart** — klart.co. Curated colour palettes from real designs.
- **Cohesive Colors** — cohesivecolors.com. Applies a colour wash to any
  palette to make it feel unified — good sanity-check technique to lift a
  scattered palette.

## How to cite

In the output, cite as: **source · specific entry / site name**. Examples:

- *Pattern from Awwwards · Locomotive Berlin (dense grid hero).*
- *Pattern from CollectUI · daily 057 (sign-in card with side illustration).*
- *Pattern from Framer templates · "Sable" (scroll-driven feature reveal).*

Never cite without the specific entry — "from Awwwards" alone is useless
and gives the user no way to verify or explore further.

## Extraction over cloning

When you name a source, isolate the transferable idea:

- ✅ *Big-serif-on-colour-block hero pattern from Awwwards · Klim Type.*
  Apply with the target's own serif + accent, not a copy of Klim's exact
  colours.
- ❌ *Copy Klim's hero.* Never.
- ✅ *Sticky vertical section counter, like Locomotive.* Reasonable.
- ❌ *Rebuild Locomotive's whole scroll system.* Overreach — cost too high
  for the transfer benefit.

## When the reference is a competitor

If the user shares a competitor site as reference, do two things:

1. Distil what they seem to like from it into the five-to-seven traits from
   step 3 of `SKILL.md`. Do not propose porting the competitor's layout.
2. Suggest at least one *different* source (not the competitor) that hits
   the same traits — this stops the design becoming a copy and gives the
   user options.
