# Voices — named aesthetic reference points

Personal library of aesthetics the user might name in a brief ("make it
feel like Kage", "the palette from Towers"). Each entry captures the
transferable traits, not a wholesale imitation target.

Add to this file when the user names a new voice. Ask for two or three
concrete traits if you're not sure what the name evokes for them.

---

## Kage

Repo: github.com/MengTo/kage. Meng To's design experiment.

**Traits:**

- Ultra-minimal type-first hero, single sans display with generous line
  height.
- Monochrome palette with a single warm accent.
- Content-forward — the site is largely text, layout is what carries the
  personality.
- No decorative imagery; typography is the ornament.

**Transfer:** when a target wants to feel restrained, editorial,
type-driven. Not a fit when the target has product screenshots or
data-viz that need to breathe.

---

## Towers

Repo: github.com/MengTo/towers. Meng To.

**Traits:**

- Vertical scroll narrative with pinned sections.
- Layered depth via `transform` and `filter`, subtle parallax.
- Editorial serif for headlines, geometric sans for body.
- Palette pulls from architectural photography — cool concrete tones,
  one warm accent.

**Transfer:** when a target is a portfolio, case study, or long-form
brand story that benefits from scroll-as-storytelling. Not a fit for
utility pages, documentation, or dashboards.

---

## Sketchbook

Repo: github.com/MengTo/sketchbook. Meng To.

**Traits:**

- Handmade / sketch feel via texture overlays, off-white paper background.
- Warm colour palette, low contrast between neighbouring elements.
- Type mixes a display serif with a rougher sans.
- Micro-interactions on hover that feel physical (subtle rotate, ease-out
  with overshoot).

**Transfer:** when the target is personal, portfolio, or brand-story
work that benefits from warmth and craft. Not a fit for product,
enterprise, or anything that needs to feel precise.

## How to use this file

- User names a voice → look it up here first.
- Not in the file → ask for two to three traits, propose the transferable
  ones, then offer to add the voice to this file at the end of the pass.
- Traits should be concrete (colour temperature, type category, motion
  density, decoration level), not vibes ("cool", "premium", "modern").

## Traits worth capturing per voice

Use this shape when adding a new entry:

1. **Type** — display + body category, weight, treatment.
2. **Palette** — temperature, contrast level, accent count.
3. **Layout** — grid rhythm, whitespace, edge treatment.
4. **Motion** — density, vocabulary, scroll behaviour.
5. **Decoration** — imagery, texture, illustration.
6. **When to reach for it / when not to.**
